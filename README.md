## Systems Philosophy

```javascript
const principles = Object.freeze({
  peopleFirst: true,
  privacyByDefault: true,
  clarityOverComplexity: true,
});

function buildWithPurpose(idea) {
  const system = design(idea, principles);
  const outcome = learnFrom(ship(system));

  return outcome.helpsPeople
    ? improve(system, outcome)
    : rethink(idea, outcome);
}
```
